# Year 2 Computer Skills Games

Free click-and-play games for Year 2 (ages 6–7), made by Ms. El Ghemary.

**Play online:** https://elghemary.github.io/Fix-the-Words/

| Game | What children practise |
|---|---|
| [Wake Up, Computer!](https://elghemary.github.io/Fix-the-Words/wake-up-computer/) | Switching on, logging on, logging off and shutting down |
| [Safe Computer Stars](https://elghemary.github.io/Fix-the-Words/safe-computer-stars/) | Staying safe with computers (listen and choose thumbs up or down) |
| [Fix the Words](https://elghemary.github.io/Fix-the-Words/fix-the-words/) | Moving the cursor with the arrow keys, deleting and adding letters |

Each game is one self-contained web page. Nothing to install and no sign-in.
